AI Sales Call Auditor

Outsourced sales agents make thousands of calls, but one human auditor can only listen to a few. I built the full pipeline that transcribes the calls every night, scores each one against the sales scorecard with an LLM, and shows the results from vendor down to the single call.

01Problem

The sales team works with 5 outsourced vendors whose agents call prospects and also call existing customers to offer other products. Every call follows guidelines: a cordial greeting, validating the customer's data, not interrupting, discovery questions about the customer's needs, a clear offer of the products, and more.

A sales employee listened to a sample of calls from each vendor to check compliance. With an average call of about 15 minutes, only a very small share of the calls could ever be reviewed.

Before

  • One person listened to a few calls per vendor
  • About 15 minutes of audio per audited call
  • Most calls never reviewed

After

  • Every recorded call is transcribed and audited by AI
  • Score, errors and verdict for each call, with a comment per error
  • Results by vendor, supervisor, agent and campaign

02The scorecard

The auditor applies the same rules the human auditor uses. Each evaluated aspect lists critical and non-critical errors.

  1. 01
    100 points for a perfect callEvery non-critical error deducts a set number of points.
  2. 02
    85 points to passBelow the minimum, the call is rejected.
  3. 03
    Critical errors fail the callAny critical error rejects the call automatically, whatever the score.
  4. 04
    Explained verdictA rejected call states the reason it was rejected.

03Pipeline

  1. Nightly transcriptionA Python job runs from 23:00 to 07:00, outside working hours so the call platform is not overloaded. It reads the folder with all the recorded calls and sends them to a WhisperX API running on an on-premise H100 GPU. About 10k calls are transcribed per night, with agent and customer speech separated.
  2. Sensitive-data maskingA script hashes and masks credit-card data in every transcript.
  3. StorageTranscripts are saved on Google Cloud with the call, agent and campaign identifiers.
  4. AI auditA Gemini-based auditor built in Vertex AI Workbench processes all calls in batches against the scorecard.
  5. Structured resultsFor each call: the score, an evaluation and a comment for every critical and non-critical error, whether a sale was closed, and the final verdict. Everything is written to a new BigQuery table.
  6. DashboardA Next.js web app reads the table and shows the results.
  7. DeploymentThe app runs as a Cloud Run service.

04Dashboard

The dashboard shows calls audited, approved, rejected, sales closed and average score, in total and grouped along the chain of responsibility. A vendor has several supervisors and each supervisor manages several agents, so performance is visible at every level.

06Impact

  • Quality control moves from a small manual sample to auditing the recorded calls at scale
  • Every rejected call comes with a clear reason
  • Vendor, supervisor, agent and campaign performance is visible in one place
  • The human auditor can focus on the cases that need judgment
